# Axie Classic - Arena de Baneos 10v10

Archivos incluidos en este paquete (listos para subir a GitHub Pages):
- `index.html`: Estructura principal de la arena 10v10.
- `styles.css`: Estilos visuales, cuadrícula 5x2, moneda 3D y sellos de baneo.
- `app.js`: Lógica de sorteo de moneda, baneo simultáneo oculto y secuencia 1 - 2 - 1.
- `fondo-arena.jpg`: Fondo del bosque de Lunacia sin menús.

## Cómo publicarlo en GitHub Pages
1. Crea un repositorio público nuevo en GitHub (por ejemplo: `axie-ban-arena`).
2. Arrastra los 4 archivos (`index.html`, `styles.css`, `app.js` y `fondo-arena.jpg`) a la raíz del repositorio y haz clic en **Commit changes**.
3. Ve a **Settings → Pages**, selecciona la rama **main** con la carpeta **/ (root)** y guarda los cambios.
